Etiquetas HTML Básicas David Ramirez IV B

<html> ... </html>
Es la etiqueta raíz que contiene todo el contenido de la página web.

<head> ... </head>
Contiene información del documento como el título y enlaces a estilos o scripts.

<body> ... </body>
Contiene todo lo que se muestra en el navegador (texto, imágenes, etc.).

<title> ... </title>
Define el título que aparece en la pestaña del navegador.

<p> ... </p>
Representa un párrafo de texto.

<table> ... </table>
Crea una tabla.

<tr> ... </tr>
Define una fila dentro de una tabla.

<td> ... </td>
Define una celda dentro de una fila.

<th> ... </th>
Define una celda de encabezado en una tabla.

<form> ... </form>
Crea un formulario para introducir datos.

<input>
Campo de entrada (texto, botón, etc.). No necesita etiqueta de cierre.

<label> ... </label>
Describe un campo del formulario.

<select> ... </select>
Crea un menú desplegable.
